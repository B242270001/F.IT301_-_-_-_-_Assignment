## 🚀 Системийн боломжууд

### 1. Дадлага хичээл сонгох (`PracticeCourses` — `/practice`)
* **Сонгох хичээлийн картууд:** Веб систем ба технологи, Өгөгдлийн сангийн систем, Математик II (явцын хувь, өнгө, сонгосон төлөв).
* **Суралцах замын зангилаанууд (Roadmap Stepping Stones):** Duolingo маягийн интерактив замнал:
  - Дууссан хичээлүүд (Ногоон зөв тэмдэг)
  - Одоогийн хичээл (Цэнхэр/Нил ягаан гэрэлтсэн төлөв + "ДАРААГИЙН ХИЧЭЭЛ" товч popover)
  - Түгжигдсэн хичээлүүд (Цоожтой)
* **Өдрийн зорилго (Daily Goal):** 0/50 XP ахиц, 7-8 өдрийн цуврал (Streak).
* **API:** `GET /api/courses/practice`

### 2. Дадлага сонгох сорилын асуулт (`QuizQuestion` — `/quiz/:unitId`)
* **Хөтөч туслах (Mascot Guide):** Зүүн талын StudyQuest дүрслэл, үгтэй харилцах хөөс (Speech bubble).
* **3 төрлийн асуулт:**
  1. *Нэг сонголттой асуулт:* "React компонент гэж юу вэ?"
  2. *Үнэн/Худал асуулт:* "React компонентын нэр жижиг үсгээр эхлэх ёстой."
  3. *Кодын жишээтэй асуулт:* JSX syntax кодтой "Энэ компонент дэлгэцэд ямар тоо харуулах вэ?"
* **Хариултын төлөв ба шалгах:**
  - Шалгах товч идэвхжих
  - Зөв хариултын ногоон баннер + Дэлгэрэнгүй тайлбар
  - Буруу хариултын улаан баннер + Зөв хариултын заавар
* **Хичээл дууссан дэлгэц:** Шагнал +50 XP, үр дүнгийн хувь, хугацаа.
* **API:** `GET /api/quiz/:unitId`

### 3. Багшийн асуулт засах (`AdminQuestions` — `/admin/questions`)
* **Багшийн удирдлагын хэсэг:** Б. Номин (Мэдээлэл зүйн багш), нийт асуулт, нэгж, суралцагчдын статистик.
* **Хайлт ба шүүлтүүр:** Нэрээр хайх, Нэгжээр шүүх, Нийтэлсэн/Ноорог төлөвөөр шүүх.
* **Асуултын CRUD үйлдлүүд:**
  - `POST /api/admin/questions` — Шинэ асуулт үүсгэх маягт (Валидаци: алдааны мэдэгдлүүд, зөв хариултыг заах radio, нэмэлт сонголт нэмэх/хасах).
  - `PUT /api/admin/questions/:id` — Байгаа асуултыг засаж шинэчлэх.
  - `DELETE /api/admin/questions/:id` — Асуулт устгах.
  - `GET /api/admin/questions` — Асуултын жагсаалт шүүлтүүртэйгээр авах.
