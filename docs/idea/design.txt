# 🏆 StudyQuest — Gamified University Learning Platform

## 1. Төслийн ерөнхий тойм ба Архитектур

**StudyQuest** нь их сургуулийн оюутнуудад зориулсан, лекцийн агуулгад суурилсан шалгалтад бэлдэх тоглоомжуулсан интерактив платформын веб прототип юм. Төслийн гол философи нь Duolingo-ийн суралцах ба суралцагчийг урамшуулах механикийг оюутны тохилог виртуаль өрөөний орчинтой хослуулан бүтээсэн явдал юм.

## 2. Дизайн систем ба Визуал идентити (Design System)

Платформ нь их сургуулийн академик түвшинд тохирсон, сэтгэл татам, орчин үеийн цэвэрхэн харагдацтай байна.

* **Үндсэн брэнд ягаан (Primary Accent):** `#7C5CFC`
* **Ягаан ховер төлөв (Primary Purple Hover):** `#6845E8`
* **Цайвар ягаан дэвсгэр (Light Purple Background):** `#F3F0FF`
* **Үндсэн дэвсгэр өнгө (Main Background):** `#F7F8FC`
* **Картын дэвсгэр (Card Background):** `#FFFFFF`
* **Үндсэн бичвэр (Main Text):** `#252538`
* **Туслах бичвэр (Secondary Text):** `#77778C`
* **Амжилт / Зөв хариулт (Success Green):** `#58CC02`
* **Шагнал / Сtreak (Reward Yellow):** `#FFC857`
* **Алдаа / Буруу хариулт (Error Red):** `#FF5B6E`

* **Фонт:** Inter (Modern Sans-serif)
* **Авцалдааны өнцөг (Border Radius):**
* Карт болон модал цонхнууд: `16px – 20px`

* **Дэлгэцийн стандарт хэмжээ:** `1440px × 900px` (Desktop-first)

## 3. Дэлгэц тус бүрийн дэлгэрэнгүй бүтэц ба харилцан үйлчлэл

### 🌙 Дэлгэц 1 — Login: Wake Up the Student (Нэвтрэх хэсэг)

Энэхүү дэлгэц нь шөнийн цагаарх тохилог оюутны өрөөний дүрслэлээр эхэлнэ.

* **Визуал орчин:**
* Орон дээрээ тайван унтаж буй оюутны дүр (Student character).
* Ширээн дээрх унтарсан компьютер, номын тавиур дээрх өнгө өнгийн номууд.
* Цонхоор харагдах одон орон бүхий шөнийн тэнгэр.
* Орон хажуугийн тавиур дээрх сүүлчийн цаг болон зөөлөн дулаан гэрэлтүүлэг.


* **Нэвтрэх форм (Floating Login Panel):**
* Баруун эсвэл төв хэсэгт тунгалагдуу цагаан карт дээр:
* **Агуулга:** StudyQuest лого, *"Өглөөний мэнд!"*, *"Хичээлдээ бэлэн үү?"*
* **Инпут талбарууд:**
* `Оюутны код` (Student ID)
* `Нууц үг` (Password)


* **Товчлуур:** Primary Purple өнгөтэй **"Сэрэх"** товч.
* *(Тэмдэглэл: Бүртгүүлэх холбоос болон бусад илүүдэл сонголт байхгүй)*.


* **Сэрэх интерактив үйлдэл (Login Transition Sequence):**
1. Хэрэглэгч нэвтрэх мэдээллээ оруулж **"Сэрэх"** дээр дарахад цонхоор наран мандах, дулаан өнгөний гэрэлтүүлэг орж ирнэ.
2. Сэрүүлэг дуугарах эсвэл дохио өгөх хөдөлгөөнт эффект (Alarm Animation) явагдана.
3. Оюутны дүр нүдээ нээж, орноосоо босох анимейшн тоглогдоно.
4. Нүүр дэлгэц болох Виртуаль өрөөний дашборд руу шилжинэ.

### ☀️ Дэлгэц 2 — Virtual Room Dashboard (Виртуаль өрөөний дашборд)

Системийн гол навигацийн зангилаа дэлгэц. Оюутан цэсүүдийг ашиглахын оронд өрөөн дэх биетүүд дээр дарж сүүлийн үеийн навигацийг хийнэ.

```
+-----------------------------------------------------------------------+
|  StudyQuest  |  👤 Бат-Эрдэнэ  |  ⚡ 350 XP  |  🔥 5 Өдөр  |  🏆 [Rank]  | <- Top HUD
+-----------------------------------------------------------------------+
|                                                                       |
|      +---------------+                 +---------------+              |
|      |  📚 Bookshelf |                 |  🏆 Trophy    |              |
|      |   (Explore)   |                 | (Leaderboard) |              |
|      +---------------+                 +---------------+              |
|                                                                       |
|                               +------------------+                    |
|                               |  💻 Desk/PC      |                    |
|                               |   (Practice)     |                    |
|                               +------------------+                    |
|       +----------------+                                              |
|       |  🛏️ Bed        |               +-----------------------+      |
|       |  (Log out)     |               | 🎯 Өнөөдрийн зорилго   |      |
|       +----------------+               |    40 / 60 XP         |      |
|                                        +-----------------------+      |
+-----------------------------------------------------------------------+

```

* **Гүйлгэгдэх интерактив биетүүд (Interactive Objects):**
* **🛏️ Ор (Bed) — Гарах:** Hover хийхэд *"Амрах / Гарах"* тохиргоо харагдах ба дарахад гарах эсэхийг баталгаажуулах цонх (Modal) гарч, зөвшөөрвөл Login дэлгэц рүү буцна.
* **💻 Ширээний компьютер (Computer) — Practice:** Hover хийхэд ягаан гэрэлтэлт үүсэж *"Practice — Шалгалтад бэлдэх"* тохиргоо гарч ирнэ. Дарснаар **Practice** дэлгэц рүү шилжинэ.
* **📚 Номын тавиур (Bookshelf) — Explore:** Hover хийхэд *"Explore — Мэдлэгийн сан"* tooltip гарна. Дарснаар **Explore** дэлгэц рүү шилжинэ.
* **🏆 Ханан дахь цом/самбар (Trophy/Board) — Leaderboard:** Дарснаар **Leaderboard** дэлгэц нээгдэнэ.


* **Top HUD & Өдрийн даалгавар:**
* Дээд хэсэгт: Лого, Оюутны нэр, Нийт цуглуулсан XP, Дараалсан өдрүүдийн цуврал (Streak count), Эрэмбийн икон.
* Баруун доод өнцөгт өдрийн зорилгын жижиг карт: *"Өнөөдрийн зорилго: 40 / 60 XP"*.

### 📝 Дэлгэц 3 — Practice: Course Folders, Horizontal Path & Quiz

Энэхүү дэлгэц нь хичээл сонгох, замаар ахих болон асуултад хариулах 3 үндсэн шатлалтай.

#### A. Хичээлийн хавтаснууд (Course Selection Grid)

Оюутан бэлдэх хичээлээ сонгоно.

* **Гол хичээл:** **"Веб систем ба технологи"** (Онцлон харуулсан)
* **Бусад хичээлүүд:** "Үйлдлийн систем", "Өгөгдлийн сан"
* **Карт дээрх мэдээлэл:** Хичээлийн нэр, дүрс тэмдэг, боломжит нэгжийн тоо, биелэлтийн хувь %, Progress bar, *"Үргэлжлүүлэх"* товч.

#### B. Хэвтээ сургалтын зам (Horizontal Learning Path)

Дэлгэц дээр баруун зүүн тийш скролл хийгдэх, Duolingo стилийн **хэвтээ чиглэлтэй** (Horizontal) замын загвар.

```
[ Section 1: Вебийн үндэс ] --------------> [ Section 2: Frontend технологи ]
  (✓) Unit 1: Вебийн архитектур              (⚡) Unit 1: HTML ба CSS (Одоогийн)
  (✓) Unit 2: HTTP ба HTTPS                  (🔒) Unit 2: JavaScript
  (✓) Unit 3: Client ба Server               (🔒) Unit 3: React үндэс

```

* **Нэгжийн (Node) төлөвүүд:**
* `Completed`: Ногоон өнгөтэй, зөв тэмдэгтэй (✓).
* `Current`: Тод ягаан `#7C5CFC` өнгөтэй, гэрэлтсэн эффекттэй.
* `Available`: Нээгдсэн энгийн зангилаа.
* `Locked`: Саарал өнгөтэй, цоожны иконтой.



#### C. Quiz & Answer Feedback (Асуулт хариулт ба Үр дүн)

* **Интерфэйс:** Дээд хэсэгт асуултын дугаар, XP шагнал, Progress Bar. Баруун талд оюутны дүр туслахаар зогсоно.
* **Асуултын төрлүүд:**
1. Сонгох асуулт (Multiple-choice)
2. Үнэн / Худал (True/False)
3. Кодын гаралт таах (Predict code output)


* **Хариултын систем (Inline Feedback):**
* Хариулт сонгож **"Шалгах"** дээр дарахад:
* **Зөв хариулт:** Ногоон хүрээ, зөв тэмдэг, яагаад зөв бэ гэдэг богино тайлбар.
* **Буруу хариулт:** Улаан хүрээ, зөв хариултыг зааж өгөх ба учир шалтгааны тайлбар.
* Товчлуур **"Дараагийн асуулт"** болж өөрчлөгдөнө.




* **Quiz Completion (Төгсгөлийн үр дүн):**
* Нийт оноо, Зөв хариулсан хувь %, цуглуулсан **XP** (+40 XP), дахин давах шаардлагатай сэдвүүдийн жагсаалт.
* **Товчлуурууд:** *"Дахин оролдох"*, *"Өрөө рүү буцах"*.
* *Нэмэгдсэн XP нь шууд хэрэглэгчийн нийт оноонд орж, Leaderboard-д нөлөөлнө.*

### 📖 Дэлгэц 4 — Explore: Interactive Knowledge Library

Лекцийн агуулгыг текстээр биш, интерактив визуал ба туршилтаар ойлгоход зориулагдсан Мэдлэгийн сан.

```
+-----------------------------------------------------------------------+
| 👈 Өрөө рүү буцах  |  Веб систем ба технологи > React Components      |
+-----------------------------------------------------------------------+
| [ Сэдвүүд ]       |  🧩 React Components                             |
| - Client-Server   |  -----------------------------------------------  |
| - HTTP Request    |  [ Visual Interactive Diagram ]                   |
| - HTML Structure  |  +---------------------------------------------+  |
| - JS Events       |  |  [App Component]                            |  |
| > React Comp.     |  |   ├── [Header Component]                    |  |
| - Props & State   |  |   └── [Content Component]                   |  |
|                   |  +---------------------------------------------+  |
|                   |  < Render хийх >  -- (Интерактив товчлуур)        |
|                   |                                                   |
|                   |  ```jsx                                           |
|                   |  function App() { return <Header/>; }             |
|                   |  ```                                              |
|                   |                                                   |
|                   |  [ Knowledge Check: 2 асуулт ]                    |
+-----------------------------------------------------------------------+

```

* **Гол онцлог интерактив демонстраци (Жишээ: React Components):**
* **Визуал схем:** Parent (App) болон Child (Header, Content) бүрэлдэхүүн хэсгүүдийн шатлалыг харуулсан карт.
* **Үйлдэл:** **"Render хийх"** товчийг дарахад эх компонент эхэлж уншаад дараа нь хүү компонентуудыг дарааллан хэрхэн дэлгэцэнд буулгаж буйг анимейшнээр шат дараатай харуулна.
* Хажууд нь кодын синтакс тодорсон код (Syntax Highlighting) харагдана.


* **Бусад сэдвүүдийн визуал дүрслэлүүд:**
* Client–Server: Хүсэлт ба хариу шилжих сумтай урсгал.
* HTTP Request/Response: Header болон Body өгөгдлийн задгай дүрслэл.
* State Changes: Дэлгэцийн төлөв өөрчлөгдөх хувьсал.


* **Knowledge Check:** Сэдэв бүрийн төгсгөлд 2-3 жижиг асуулт ажиллаж, сэдвийг "Дууссан" төлөвт оруулж, Explore хэсгийн ахицыг шинэчилнэ.

### 🏆 Дэлгэц 5 — Leaderboard (Лидерборд)

Оюутнуудын Practice хэсгээс цуглуулсан нийт XP оноонд суурилсан чансааны дэлгэц.

```
                      +-------------------+
                      |   🥇 1-р байр     |
                      |   Бат-Эрдэнэ      |
                      |    1,240 XP       |
  +-------------------+-------------------+-------------------+
  |   🥈 2-р байр     |                   |   🥉 3-р байр     |
  |     Номин         |                   |    Тэмүүлэн       |
  |    1,120 XP       |                   |     980 XP        |
  +-------------------+-------------------+-------------------+

-----------------------------------------------------------------
4 |  🎯 Чи (Саруул)               | 890 XP (+40)  |  ▲ 1
5 |  Болд                          | 820 XP        |  ▼ 1

```

* **Сонголт:** *"Энэ долоо хоног"* болон *"Нийт"* гэсэн хугацааны шүүлтүүртэй.
* **Шилдэг 3 Оюутан (Podium View):** Медаль, Аватар дүрс, Оюутны нэр, Цуглуулсан оноо бүхий өндөрлөг бүтэц.
* **Жагсаалт:**
* Чансааны дугаар, Аватар, Нэр, Нийт XP, Эрэмбийн өөрчлөлт (▲ / ▼).
* **Нэвтэрсэн оюутны мөр:** Ягаан өнгийн дэвсгэрээр тодорч **"Чи"** гэсэн тусгай тэмдэглэгээтэй байна.


* **Өгөгдлийн синхрончлол:** Practice дээр тест амжилттай өгч авсан XP нь шууд Leaderboard-ийн оноог бодитоор нэмэгдүүлж, эрэмбийг ахиулна.

## 4. Навигаци ба Системийн урсгал (System User Journey)

Оюутны платформоор аялах үндсэн урсгалууд тус бүрдээ тодорхой бөгөөд логик холбоотой:

1. **Үндсэн сургалтын урсгал:**
`Login (Сэрэх)` ➔ `Virtual Room (Компьютер дээр дарах)` ➔ `Practice (Хичээл сонгох)` ➔ `Хэвтээ сургалтын зам` ➔ `Quiz өгөх` ➔ `Үр дүн ба XP авах` ➔ `Leaderboard (Оноо ахисныг харах)`
2. **Мэдлэг гүнзгийрүүлэх урсгал:**
`Virtual Room (Номын тавиур дээр дарах)` ➔ `Explore (Сэдэв сонгох)` ➔ `Интерактив Демо харах` ➔ `Knowledge Check` ➔ `Ахиц шинэчлэгдэх`
3. **Системээс гарах урсгал:**
`Virtual Room (Орон дээр дарах)` ➔ `Гарахыг баталгаажуулах` ➔ `Login Screen (Унтаж буй оюутан)`

Энэхүү UI/UX концепц ба функцүүдийн бүтэц нь **StudyQuest** платформыг суралцахад урам зориг өгөхүйц, ойлгомжтой бөгөөд их сургуулийн орчинд бүрэн тохирсон бүтээгдэхүүн болгож байна.
