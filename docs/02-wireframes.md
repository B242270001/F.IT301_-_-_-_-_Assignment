# 02. Дэлгэцийн ноорог ба Төлөвүүд (Wireframes & UI States)

## [TASK-01] А. Төгөлдөр — Нэвтрэх ба Хянах самбар

### 1.1 Нэвтрэх хуудас (Login Screen)
- **Талбарууд:** Student ID (`input[text]`), Password (`input[password]`).
- **Товчлуурууд:** `Сэрэх` (Primary Purple Button `#7C5CFC`).
- **Шилжилт:** "Сэрэх" товч дарагдахад нар мандах анимейшн явагдаж `Virtual Room Dashboard` руу шилжинэ.
- **Алдааны төлөв (Error State):** Оюутны код эсвэл нууц үг буруу үед инпут доор `#FF5B6E` өнгөөр "Оюутны код эсвэл нууц үг буруу байна" гэж харуулна.
- **Ачааллах төлөв (Loading State):** "Сэрэх" товчлуур дээр спиннер эргэнэ.

### 1.2 Хянах самбар (Virtual Room Dashboard)
- **Бүрэлдэхүүн:** Top HUD (Нэр, ⚡ XP, 🔥 Streak), Интерактив 4 биет (💻 Компьютер, 📚 Номын тавиур, 🏆 Цом, 🛏️ Ор), Өдрийн зорилго карт.
- **Шилжилт:** 
  - 💻 Компьютер ➔ `PracticeCourses` [TASK-02]
  - 📚 Номын тавиур ➔ `ExploreCourses` [TASK-05]
  - 🏆 Цом ➔ `Leaderboard` [TASK-06]
  - 🛏️ Ор ➔ Log out Modal ➔ Login Screen

---

## [TASK-02] Мөнхбаяр — Дадлагын сонголт ба асуулга

### 2.1 Дадлага хичээл сонгох (Practice Courses)
- **Талбарууд:** Хичээлийн карт (Нэр, Икон, Прогресс багц, Биелэлтийн %).
- **Товчлуурууд:** `Эхлэх / Үргэлжлүүлэх`, `Өрөө рүү буцах`.
- **Шилжилт:** Хичээл дээр дарахад `HorizontalPath` [TASK-03] руу шилжинэ.
- **Хоосон төлөв (Empty State):** Бэлтгэсэн дадлага байхгүй үед "Одоогоор идэвхтэй дадлага олдсонгүй" карт харуулна.

### 2.2 Дадлага сонгох асуулт (Quiz Question)
- **Талбарууд:** Асуултын агуулга, Асуултын дугаар, XP Шагнал, Хариултын сонголтууд (Radio/Cards), Код таах хэсэг.
- **Товчлуурууд:** `Шалгах`, `Дараагийн асуулт`.
- **Алдааны төлөв (Wrong Answer):** Улаан хүрээ (`#FF5B6E`), зөв хариултын тайлбар харуулна.
- **Амжилттай төлөв (Correct Answer):** Ногоон хүрээ (`#58CC02`), зөв хариулсны тайлбар.

---

## [TASK-03] Тэмүүлэн (Temka) — Суралцах зам ба Сэдвийн жагсаалт

### 3.1 Дадлага суралцах зам (Horizontal Path)
- **Бүрэлдэхүүн:** Хэвтээ чиглэлд скролл хийгдэх Нэгжүүд (Completed, Current, Locked зангилаанууд).
- **Шилжилт:** Идэвхтэй Unit дээр дарахад `QuizQuestion` [TASK-02] нээгдэнэ.
- **Төлөвүүд:** Locked нэгж дээр дарахад "Өмнөх нэгжийг дуусгана уу" хөвөгч тохиргоо харуулна.

### 3.2 Судлах сэдвийн жагсаалт (Unit Topics)
- **Бүрэлдэхүүн:** Сэдвүүдийн жагсаалт, Нэгжийн нэр, Прогресс ахиц.

---

## [TASK-04] Д. Баттөмөр — Дадлагын үр дүн ба Кодчиллын дүн

### 4.1 Дадлага хичээлийн үр дүн (Quiz Result)
- **Талбарууд:** Нийт оновч %, Нийт цуглуулсан XP (+40 XP), Дахин давах шаардлагатай сэдвүүд.
- **Товчлуурууд:** `Дахин оролдох`, `Өрөө рүү буцах`.

### 4.2 Дадлага кодын үр дүн (Code Output Result)
- **Талбарууд:** Кодын ажиллагааны гаралт, Амжилттай/Алдаатай ажилласан лог.

---

## [TASK-05] Хүслэн О. — Судлах хичээл ба Лекцийн сан

### 5.1 Судлах хичээлийн сан (Explore Courses)
- **Бүрэлдэхүүн:** Хичээлүүдийн карт, Тодорхойлолт, Прогресс бар.
- **Шилжилт:** Хичээл дарахад `ExploreLectureDetail` руу шилжинэ.

### 5.2 React лекцийн дэлгэрэнгүй (Explore Lecture Detail)
- **Бүрэлдэхүүн:** Зүүн меню (Сэдвүүд), Төв хэсэг (Текст, Интерактив Демо карт), Код болон `Render хийх` товчлуур.
- **Knowledge Check:** Сэдвийн төгсгөлд 2 асуулт бүхий тест.

## [TASK-06] Цогжавхлан Б. — Чансаа ба Явцын төлөв / Тест

### 6.1 Долоо хоногийн чансаа (Leaderboard)
- **Бүрэлдэхүүн:** Шилдэг 3 (Podium), Бусад оюутнуудын жагсаалт, "Чи" тодорсон мөр, Хугацааны шүүлтүүр (`Энэ долоо хоног` / `Нийт`).

### 6.2 StudyQuest харагдах төлөвийн хуудас (Global UI States & Tests)
- **Бүрэлдэхүүн:** Системийн сүлжээний алдаа, Хоосон төлөвүүд, Глобал Modal цонхнууд.
