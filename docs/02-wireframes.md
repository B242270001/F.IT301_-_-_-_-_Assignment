# 02. Дэлгэцийн ноорог ба Төлөвүүд (12 Pages/Routes)

## [TASK-01] А. Төгөлдөр
### 1. Page `/login` — Нэвтрэх хуудас
- **Талбар:** Оюутны код / Нууц үг, Эрх сонгох (Student / Teacher).
- **Товчлуур:** `Сэрэх`.
- **Төлөв:** Алдаатай нууц үгэнд улаан анхааруулга, ачаалж байхад спиннер.

### 2. Page `/dashboard` — Виртуаль өрөөний самбар
- **Элементүүд:** Компьютер (Practice), Номын тавиур (Explore), Цом (Leaderboard), Ор (Logout Modal).
- **HUD:** XP, Streak, Өдрийн зорилго.

---

## [TASK-02] Мөнхбаяр
### 3. Page `/practice` — Дадлага хичээл сонгох
- **Элементүүд:** Хичээлүүдийн карт, Прогресс бар, `Үргэлжлүүлэх` товч.

### 4. Page `/quiz/:unitId` — Асуулт хариултын дэлгэц
- **Элементүүд:** Сонгох, Үнэн/Худал, Код таах асуултууд. Inline Feedback (Ногоон/Улаан).

### 5. Page `/admin/questions` — [Teacher/CRUD 1] Асуултын банк удирах
- **Элементүүд:** Шинэ асуулт нэмэх форма (Create), Засах форма (Update), Жагсаалт, Устгах товч (Delete).

---

## [TASK-03] Тэмүүлэн (Temka)
### 6. Page `/practice/:courseId` — Дадлага суралцах хэвтээ зам
- **Элементүүд:** Баруун-зүүн тийш скролл хийх Хэвтээ зам. Completed, Current, Locked зангилаанууд.

### 7. Page `/topics` — Судлах сэдвийн жагсаалт
- **Элементүүд:** Нэгж доторх сэдвүүдийн жагсаалт, Ахицын хувь.

---

## [TASK-04] Д. Баттөмөр
### 8. Page `/quiz/result` — Дадлагын үр дүн
- **Элементүүд:** Зөв хариултын %, Цуглуулсан XP (+40 XP), Дахин оролдох товч.

### 9. Page `/admin/courses` — [Teacher/CRUD 2] Хичээлүүд удирах
- **Элементүүд:** Шинэ хичээл нэмэх modal (Create), Засах (Update), Устгах баталгаажуулалт (Delete).

---

## [TASK-05] Хүслэн О.
### 10. Page `/explore` — Лекцийн сан (Search & Filter)
- **Элементүүд:** Хайлтын инпут (`Search Input`), Хичээлийн ангилал, Лекцийн карт.

### 11. Page `/explore/lecture/:id` — Интерактив лекцийн дэлгэрэнгүй
- **Элементүүд:** Зүүн меню, Төв хэсэгт Интерактив Демо (Render хийх товч), Knowledge Check 2 асуулт.

---

## [TASK-06] Цогжавхлан Б.
### 12. Page `/leaderboard` — Чансааны жагсаалт
- **Элементүүд:** Шилдэг 3 Оюутан (Podium), Бусад оюутнуудын жагсаалт, "Чи" тодорсон мөр.

### 13. Page `/ui-states` — Харагдах төлөвийн ба Тестийн хуудас
- **Элементүүд:** Хоосон төлөв (Empty State), Сүлжээний алдаа (Network Error State), Глобал Модалууд.
