# 01. Санаа ба асуудал — StudyQuest

## Асуудал

Их сургуулийн оюутнууд онолын хичээлийн шалгалтад бэлдэхдээ урт текст уншиж, идэвхгүй суралцдаг. Үүнээс болж мэдлэг тогтохгүй, сургалтад хөдөлгөөнгүй болдог. Багш нар хичээл, лекц, материалаа нэг дор удирдаж, оюутны ахицыг харах хэрэгсэлгүй байна.

## Шийдэл

**StudyQuest** нь Duolingo-ийн тоглоомжуулсан механик (XP, Streak, Leaderboard) болон оюутны виртуаль өрөөний орчинг хослуулсан веб платформ юм.

- **Оюутан** виртуаль өрөөнөөс дадлага, судлах хэсэг, чансаа руу орно. Хэвтээ замаар ахиж, quiz өгч, XP цуглуулна.
- **Багш** хичээл, материал, лекцээ нэмж засна, устгана. Суралцагчид болон статистикийг харна.

## Хэрэглэгч ба эрх (2 role)

| Role | Хийж чадах зүйл | Хийж чадахгүй зүйл |
|---|---|---|
| Зочин | Зөвхөн `/login` хуудсыг үзнэ | Бусад хуудсанд "Нэвтэрнэ үү" төлөв харна |
| `STUDENT` (Оюутан) | Dashboard, дадлага (`/practice`, зам, quiz, үр дүн), хичээлийн сан, сэдэв, лекц, чансаа | Дадлага/quiz өгөх (`/practice*`, `/quiz/*`), чансаанд оролцох |
| `TEACHER` (Багш) | Dashboard, хичээлийн сан, сэдэв, лекц, чансаа, багшийн өрөө, хичээл нэмэх/засах/устгах, лекц засах/устгах | `/teacher*` хуудас, лекц засах/устгах |

## Гол хэрэглэгчийн урсгал

1. **Оюутны сургалтын урсгал:** Нэвтрэх → Dashboard → Компьютер (Дадлага) → Хичээл сонгох → Суралцах зам → Quiz (сонгох, үнэн/худал, кодын үр дүн) → Үр дүн ба XP → Чансаа.
2. **Мэдлэг гүнзгийрүүлэх урсгал:** Dashboard → Номын тавиур → Хичээлийн сан (хайх, шүүх) → Сэдвийн жагсаалт → Лекц → Knowledge Check.
3. **Багшийн урсгал:** Нэвтрэх → Dashboard → Удирдах самбар → Багшийн өрөө (статистик, суралцагч, хичээлийн жагсаалт) → Хичээл нэмэх (мэдээлэл, материал, лекц) → Засах → Устгах.
4. **Гарах урсгал:** Dashboard → Ор → Баталгаажуулах → Login.

### Сэдвийн доод шаардлагатай тулгалт

| Шаардлага | StudyQuest-ийн хэрэгжилт |
|---|---|
| 2+ role | `STUDENT`, `TEACHER` |
| User-ээс гадна 3+ entity | Course, Unit, Topic, Lecture, QuizQuestion, QuizAttempt, UserProgress, TopicProgress |
| 12+ route | 12 route (дээрх хүснэгт) |
| 10+ REST endpoint | 22 endpoint ([04-api-pages.md](04-api-pages.md)) |
| 2 entity дээр CRUD | **Course** (Create: `/teacher/courses/new`, Read: `/teacher`, `/explore`, Update ба Delete: `/teacher`). **Lecture** (Create: `/teacher/courses/new`, Read: `/explore/lecture/:id`, Update ба Delete: `/explore/lecture/:id` дахь багшийн товч) |
| Жагсаалтад хайлт/шүүлт | `/explore` (хайлт + ангиллын шүүлт) |
| Dashboard/статистик | `/teacher` (статистик), `/dashboard` (HUD) |
| Authentication + authorization | Нэр/нууц үгээр нэвтрэх, role-аар хуудас болон UI хамгаалах |
| Responsive | Desktop, tablet, mobile (375px-д хэвтээ scroll үүсэхгүй) |

## Хамрахгүй хүрээ

Бодит төлбөр, бүртгүүлэх (sign up) урсгал, бодит цагийн чат, видео лекц stream хийх, багшаас асуулт нэмэх тусдаа хуудас (асуултын сан нь seed data-аар өгөгдөнө).
