# 01. Санаа ба асуудал (Idea & Scope)

## 1. Асуудал ба Шийдэл
- **Асуудал:** Их сургуулийн оюутнууд лекцийн онолын хичээлүүдэд бэлдэхдээ уйтгартай урт текст уших, идэвхгүй байдлаар суралцсанаас болож шалгалтад хангалтгүй бэлддэг.
- **Шийдэл:** Duolingo-ийн тоглоомжуулсан механик (XP, Streak, Leaderboard) болон оюутны өрөөний интерактив орчныг хослуулсан **StudyQuest** платформоор дамжуулан сонирхолтой бөгөөд интерактив хэлбэрээр шалгалтад бэлдэх.

## 2. Хэрэглэгчийн Эрх / Role (2 эрх)
1. **Student (Оюутан):** Виртуаль өрөөгөөр навигаци хийх, дадлага тест өгөх, XP цуглуулах, лекц үзэх, чансаа харах.
2. **Teacher / Admin (Багш):** Дадлага хичээл шинээр үүсгэх, засах, устгах, асуултын банк болон лекцүүдийг удирах (CRUD).

## 3. Гол үйлдэл ба Хамрах хүрээ
- **Оюутны хэсэг:** Нэвтрэх (Унтаж буй оюутныг сэрээх) ➔ Виртуаль өрөөний дашборд ➔ Хэвтээ замаар ахиж дадлага хийх ➔ Интерактив лекц үзэх ➔ Чансаа ахих.
- **Багшийн хэсэг:** Админ цонхоор хичээл (Course) болон Асуулт (QuizQuestion) дээр **CRUD** ажиллагаа хийх.
- **Мобайл ба Веб:** Дэлгэцийн хэмжээнээс хамаарч хариу үйлдэл үзүүлдэг (Responsive).
