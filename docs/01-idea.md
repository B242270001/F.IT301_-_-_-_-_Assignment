## 1. Санаа ба Шийдвэрлэх Асуудал (Problem & Idea)

### 1.1 Шийдвэрлэх Асуудал (Problem)
Их, дээд сургуулийн оюутнууд семестрийн ба улирлын шалгалтад бэлдэх үед дараах нийтлэг хүндрэлүүдтэй тулгардаг:
1. **Уйтгартай, идэвхгүй сургалтын материал:** Уламжлалт лекцийн слайд, урт текстэн PDF материалууд нь оюутны анхаарлыг тогтоох, суралцах урам зоригийг дэмжихэд хангалтгүй байдаг.
2. **Дасгал ажил ба Тестийн хомсдол:** Лекцийн онолын мэдлэгийг шалгах интерактив дасгал, шалгалтын түвшний тестүүд нэгдсэн нэг системд дутагдалтай байдаг.
3. **Ахиц дэвшлийн тодорхойгүй байдал:** Оюутан хичээлийн агуулгыг ямар хувьтай эзэмшсэн, ямар сэдэв дээр илүү дадлага хийх шаардлагатай байгаагаа бодитойгоор үнэлэх боломж хязгаарлагдмал.

### 1.2 Санаа ба Шийдэл (Idea & Solution)
**StudyQuest** нь их сургуулийн хичээл ба лекцийн агуулгад суурилсан, **тоглоомжуулсан (gamified)** шалгалтад бэлдэх интерактив веб платформ юм.

* **Виртуаль өрөөний орчин:** Оюутан уламжлалт хүнд цэсээр навигаци хийхийн оронд өөрийн виртуаль өрөөн дэх биетүүдээр (Компьютер, Номын тавиур, Цом, Ор) дамжин системтэй харилцана.
* **Duolingo-с сэдэвлэсэн сургалтын суваг:** Хичээлүүдийг хэвтээ чиглэлтэй сургалтын зам (Horizontal Learning Path), XP оноо, Streak (цуврал өдөр), чансааны хүснэгтээр дамжуулан суралцах сонирхлыг нэмэгдүүлнэ.
* **Интерактив Мэдлэгийн сан (Explore):** Лекцийн нарийн тодорхойлолтуудыг кодын ажиллагаа, визуал диаграмм, алгоритмын алхамчилсан анимейшнээр харуулж турших боломж олгоно.

## 3. Гол Үйлдэл ба Боломжууд (Core Features)

### 3.1 Сэрэх ба Нэвтрэх (Login Sequence)
* Унтаж буй оюутны шөнийн өрөөний дүрслэл.
* Оюутны код ба нууц үгээр нэвтрэх ("Сэрэх" товч).
* Наран мандах болон сэрүүлэг дуугарах хөдөлгөөнт шилжилт (Transition sequence).

### 3.2 Виртуаль Өрөө (Interactive Bedroom Navigation)
* **💻 Компьютер (Desk/PC):** Дарахад **Practice** (Шалгалтад бэлдэх) хэсэг рүү шилжинэ.
* **📚 Номын тавиур (Bookshelf):** Дарахад **Explore** (Мэдлэгийн сан) хэсэг рүү шилжинэ.
* **🏆 Цом/Самбар (Trophy):** Дарахад **Leaderboard** (Чансаа) дэлгэц нээгдэнэ.
* **🛏️ Ор (Bed):** Дарахад системээс гарах (Log out) баталгаажуулалт гарна.
* **Top HUD:** Нийт XP, Streak (цуврал өдөр), Оюутны нэр, өдрийн зорилгын прогресс (40/60 XP).

### 3.3 Шалгалтад бэлдэх (Practice Module)
* **Хичээлийн хавтасууд:** "Веб систем ба технологи", "Үйлдлийн систем", "Өгөгдлийн сан".
* **Хэвтээ сургалтын зам (Horizontal Path):** Баруун тийш скролл хийгдэх Секц болон Юнитүүдийн зангилаа (Completed, Current, Available, Locked).
* **Квиз ба Тест:** Сонгох асуулт, Үнэн/Худал, Кодын гаралт таах асуултууд.
* **Амьд хариу үйлдэл (Inline Feedback):** Зөв/буруу хариултын тайлбар, амжилттай давбал XP оноо нэмэгдэх.

### 3.4 Интерактив Мэдлэгийн Сан (Explore Module)
* Сэдэв бүрийн визуал интерактив демонстраци (Жишээ нь: React Components render хийх ажиллагааг алхам алхмаар харах).
* Кодын синтакс тодорсон жишээнүүд.
* Сэдвийн төгсгөлийн богино мэдлэг шалгах тест (Knowledge check).

### 3.5 Лидерборд ба Чансаа (Leaderboard)
* Practice хэсгээс цуглуулсан бодит XP-д суурилсан чансаа.
* Шилдэг 3 оюутны өндөрлөг (Podium view).
* Өөрийн эрэмбэ болон онооны өөрчлөлтийг (▲/▼) онцлон харуулах.

## 4. Хамрах Хүрээ ба Хязгаарлалт (Scope & Boundaries)

### 4.1 Төслийн Хамрах Хүрээ (In Scope)
* 5 үндсэн дэлгэцийн иж бүрэн интерактив веб прототип (Desktop Frame 1440 × 900px).
* Хэрэглэгчийн үйлдлүүд дээр суурилсан local state болон mock data синхрончлол (XP, Progress, Leaderboard rank update).
* Цэвэрхэн UI/UX, ягаан брэнд өнгөний дагуух (`#7C5CFC`) дизайн систем, тохилог оюутны өрөөний концепц.

### 4.2 Хязгаарлалт ба Хасах Хүрээ (Out of Scope / Non-goals)
* Бодит Back-end сервер, Database эсвэл OAuth authentication.
* Оюутны шинээр бүртгүүлэх (Sign-up) хэсэг (Оюутны эрхийг сургуулиас урьдчилан үүсгэдэг гэж үзнэ).
* Төлбөрийн систем, чат, найзын сүлжээ гэх мэт илүүдэл функцүүд.
